# Referencias visuales Party
20 HTML originales exportados de Stitch, versionados localmente. Son referencias, NO código de producción ni especificación funcional. Pueden contener CDN, fuentes externas, ilustraciones remotas y textos de ejemplo. No copiar esas dependencias; sustituir por CSS/SVG propios y recursos locales con licencia. La línea base docs/PRODUCT-BASELINE.md prevalece: seis niveles, cinco modos, etiqueta La máquina sin personajes nombrados, salas públicas y privadas, búsqueda en segundo plano, ayudas y medallas. No introducir música, ELO, métricas inventadas ni chat. La pantalla results.html es base de todas las variantes de resultado. Las pantallas nuevas deben extender los patrones de esta carpeta. Capturas PNG originales no incluidas; verificar referencias HTML y generar evidencia de implementación local con Playwright. No asumir que la referencia ya cumple no-scroll; el criterio obligatorio es el de la línea base. No se necesita acceso a Stitch durante implementación.
